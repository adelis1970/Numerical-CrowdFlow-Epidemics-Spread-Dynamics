# Numerical-CrowdFlow-Epidemics-Spread-Dynamics
MATLAB code to reproduce the simulation results from the paper "Numerical investigation of the effect of macro control measures on epidemic transport via a coupled PDE crowd flow - epidemic spreading dynamics model" by A.I. Delis and N. Bekiaris-Liberis
